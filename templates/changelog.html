Release history for the Payment Reconciliation System

V1 Payment Module Overhaul & New Features 2026-06-02
Fixed
  • Hold Release Note misrouted as GST Release Note - keyword "release" in GST branch was catching "Hold Release Note"; added explicit hold keywords and excluded "hold" from GST match
  • Paid amount showing 0 in report - _row_paid was looking for renamed columns (Amount_after_TDS_Deduction) but SQL still aliased them as Total_Amount; fixed all aliases in UNION query
  • Amount with TDS showing 0 for contractors whose Excel had no explicit Payment_Amount column - backfilled existing rows and fixed import logic
  • Paid amount mismatch - SP was using Payment_Amount when TDS=0 instead of the correct Total_Amount; fixed all payment SPs to always prefer Total_Amount when > 0
  • GST Release history not loading after re-import - incorrect table/column references in GetGSTReleaseByIDWithName
  • Invoice save failing - SaveInvoice SP expects 20 params but was receiving 19 (missing sort_order)
  • GST Release add failing (500 error) - AddGSTReleaseFromExcel SP expects 8 params but was receiving 7 (missing sort_order)
Added
  • GST Date column - new Invoice_Date field added to GST Release table, form, history table, view modal, and downloaded Excel report
  • Balance to Debit page - new standalone page to manage per-contractor debit balances; value appears as "Balance to Debit" in the Summary section of the output Excel (replaces "Total Debit")
  • Debit notes in filtered Excel report - debit note rows from credit_note table now included in the main report UNION query and exported Excel
  • Universal payment TDS resolution - import now correctly computes Amount_with_TDS and TDS_Payment_Amount for all Excel formats: explicit Payment_Amount column, TDS_Amount-only column, or no TDS
Changed
  • Payment columns renamed - "Amount (₹)" → Amount with TDS; "Total (₹)" → Amount after TDS Deduction; DB columns renamed accordingly (Payment_Amount → Amount_with_TDS, Total_Amount → Amount_after_TDS_Deduction)
  • TDS % column removed from Payment Module - TDS Amount is now directly editable; Total auto-calculates as Amount − TDS
